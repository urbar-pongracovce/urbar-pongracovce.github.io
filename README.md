# Urbár Pongrácovce — oficiálny web

Webová stránka **Urbárskej spoločnosti pozemkového spoločenstva Pongrácovce**
(IČO 56940980, Pongrácovce 30, okres Levoča).

**Živá stránka:** https://urbar-pongracovce.github.io

## Technológie

- [Astro 5](https://astro.build) — statický generátor
- [Tailwind CSS 4](https://tailwindcss.com) — štýly
- GitHub Pages + GitHub Actions — automatické nasadenie pri každej zmene

## Správa obsahu

Oznamy, fotky a dokumenty sa pridávajú priamo cez github.com — podrobný postup je
v súbore **[NAVOD.md](NAVOD.md)** a rýchle odkazy na stránke `/admin/`.

## Vývoj

```sh
npm install
npm run dev      # lokálny náhľad na http://localhost:4321
npm run build    # produkčné zostavenie do dist/
```
